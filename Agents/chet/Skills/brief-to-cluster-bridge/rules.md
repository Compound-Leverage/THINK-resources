# Brief-to-Cluster Bridge -- Rules

- Never extract an individual organization or one-off entity as a candidate -- only
  named, bounded groups qualify, same boundary as `cluster-discovery`
- Every extracted candidate must trace back to something actually stated or clearly
  implied in the source brief -- don't infer a group's existence beyond what the brief
  supports
- Tag every record with its source brief -- a candidate with no traceable source doesn't
  ship
- If nothing in a brief resolves to a bounded group, that's a valid outcome -- don't
  force a fit just to produce output
- No em dashes in any output
