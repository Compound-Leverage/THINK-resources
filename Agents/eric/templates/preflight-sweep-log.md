# Preflight Sweep Log -- Template

Produced by `Skills/preflight-check/` at the end of each nightly sweep. Not a substitute
for a PR when a mechanical fix went out -- this log is the summary of what was checked
and what happened.

```
Preflight Sweep -- [date]
Workflows checked: [n]

YAML: [OK / FIXED -- list of files and PR URL(s)]
ACTIONS: [OK / UPDATED -- list of files and PR URL(s)]
SECRETS: [OK / MISSING -- list, or "none"]
MODEL PROVIDER KEYS: [OK / ALERT sent -- list of providers, or "none"]

STATUS: [CLEAR TO RUN / BLOCKED -- awaiting a human]
```
