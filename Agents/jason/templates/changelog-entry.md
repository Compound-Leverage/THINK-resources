# Changelog Entry -- Template

Produced by `Skills/docs-maintenance/` after a PR merges or before a push to your
production branch. One entry per push or merge -- draft only, surfaced for review before
it goes into your actual changelog file.

```
## [date] -- [branch name]

### Changed
- [file]: [what changed, one line]

### Added
- [file]: [what was added, one line]

### Removed
- [file]: [what was removed, one line]
```
