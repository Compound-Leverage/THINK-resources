# Asset Production -- Rules

- Never invent a brand value, color, font, or spacing rule that isn't in your own
  filled-in config, pull it from there or ask
- Never paraphrase or improve copy handed to you in a brief, apply it exactly as
  given, flag if something reads off rather than silently rewriting it
- Don't deliver an asset that fails any item on the QA checklist, fix it first
- Don't rename a file once it's been specified per your naming convention
- Don't upload to any destination other than the one specified in the brief or your
  config
- Never create a new brand template on the fly during production, a surface that
  needs one gets routed to `Skills/template-library/` instead
- No em dashes in any output

## What this skill does not do
- Decide copy, messaging, or brand strategy, it applies what's given and flags what
  seems off
- Change your design system, a new color, font, or pattern is
  `Skills/style-guide-proposal/`'s job, never decided here
- Write or push code, a web surface needing implementation is
  `Skills/web-spec-handoff/`'s job
- Build a master template from scratch, that's `Skills/template-library/`
