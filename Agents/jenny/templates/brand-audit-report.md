# Brand Audit Report -- Template

Produced at the end of each `Skills/brand-asset-audit/` sweep. A fuller, multi-asset
version of the "Brand audit findings" section in the base template at
`Templates/head-of-design-jenny.md`, this is the report format for a full recurring
sweep rather than a single audit trigger.

```
BRAND AUDIT -- [date]

PASS: [list asset names]

VIOLATIONS:
| Asset | Check failed | Corrected version / note |
|---|---|---|
| [asset name] | [check] | [correction, or what's needed] |

PATTERN GAPS (the same violation recurring across multiple assets):
- [description] -- routed to Skills/style-guide-proposal/

Proposed design-system changes: [describe, or "none"], routed to owner for approval
before execution
```
