# Deck Brief -- Template

Produced by `Skills/deck-spec/`. Not covered by the base "Asset/Spec Handoff"
template in `Templates/jenny-head-of-design.md`, decks get their own structured,
slide-by-slide format because the output is a full brief, not a single asset or
spec block.

```
DECK BRIEF -- [Deck Title]
Audience: [who]
Purpose: [present / workshop / training / sell]
Slide count: [n]
Visual system: [pointer to your own deck color/type/layout rules]

SLIDES:

[SLIDE 1]
Layout: [cover / problem / how-it-works / step-detail / comparison / demo / CTA / close]
Section tag: [text]
Headline: [line 1] / [line 2]
Content:
  [LABEL]: [body text]
  [LABEL]: [body text]
Footer: [your standard footer text]

[SLIDE 2]
...

[repeat per slide]
```
