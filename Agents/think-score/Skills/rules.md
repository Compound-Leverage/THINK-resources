# THINK Score Rubric

The scoring model THINK Score applies to every org-against-event assessment. Four
dimensions, 0-10 each, summing to a 0-40 total. This rubric answers one question: is
this org actually positioned to capture this specific capital event, or not.

---

## The Four Dimensions

| Dimension | What it measures |
|---|---|
| Signal Proximity | Does the org have real visibility into this event before the window narrows -- a direct line to decision-makers, or reliance on public/lagging information everyone else already has? |
| Positioning Fit | Is the org's capability already packaged as a ready answer to this specific opportunity, or would they need to build a pitch from scratch once the window opens? |
| Window Timing | How much runway is actually left -- pre-announcement/planning stage with room to position, or already deep into an active solicitation with a closing deadline? |
| Capacity to Act | Does the org have the staffing bandwidth to execute on this opportunity right now, without pulling people off other priorities or leaving the work undone? |

Score each dimension independently, 0-10. A dimension score below 3 requires a recorded
reason, not just the number -- this is what makes the gap analysis mean something instead
of reading as an arbitrary total.

**Suggested anchors per dimension** (adjust to your own scoring judgment; these are
starting points, not hard rules):

- **8-10:** Clearly true -- direct relationship, ready-packaged offer, wide-open window, or capacity fully available.
- **5-7:** Partially true -- some proximity/packaging/runway/capacity exists but has real gaps.
- **1-4:** Mostly absent -- little to no proximity/packaging/runway/capacity.
- **0:** Fully absent.

---

## Position Bands

| Total | Position | What it means |
|---|---|---|
| 0-10 | Not Positioned | The org has little to no foothold on this event yet. All four dimensions need work before this is worth active pursuit. |
| 11-20 | Early Signal | Some dimensions are developing, but the org isn't ready to move on this window yet. Build relationships and package the offer before committing resources. |
| 21-30 | Positioned, Capacity Gap | The org has real proximity, positioning, and/or timing in its favor. What's missing is usually the staffing bandwidth to execute -- this is the band where a capacity gap most often shows up. |
| 31-40 | Ready to Capture | All four dimensions are firing. The org can move on this event now. |

Bands are a starting point for how to read the total -- adjust the cutoffs to fit your
own portfolio if you find a different split reads more accurately for your sector.

---

## Gap Classification

The gap analysis in the readiness report should name the lowest-scoring dimension(s) and
classify the primary gap type:

| Lowest dimension | Gap type | What it means for the org |
|---|---|---|
| Signal Proximity | Detection Gap | The org would find out about this event too late to act, or only through public channels everyone else already sees. |
| Positioning Fit | Packaging Gap | The org has the underlying capability but hasn't translated it into a ready, presentable offer for this specific opportunity. |
| Window Timing | Timing Gap | The runway itself is the constraint -- often outside the org's control, but worth naming so effort isn't wasted chasing a window that's already closing. |
| Capacity to Act | Capacity Gap | The org knows about the opportunity and could win it, but doesn't have the people-hours to execute without displacing other priorities. This is the gap a Digital Employee placement is built to close. |

If two dimensions tie for lowest, name both gap types rather than picking one arbitrarily.
A report that flags a Capacity Gap as primary or co-primary is the one that leads directly
to a placement conversation -- say so plainly rather than burying it in the score table.

---

## What This Rubric Does Not Cover

This rubric scores the org's position relative to one capital event at a time. It does
not:

- Rank multiple events against each other for portfolio prioritization (that's a
  Strategist judgment call, informed by more than one THINK Score report)
- Score the underlying capital event itself for size, funding, or competition intensity
  (that's the cluster/opportunity map's job, upstream of this rubric -- see `schema.md`)
- Substitute for the Strategist's own read of the client relationship

Use it as one clear, repeatable input to that judgment, not a replacement for it.
