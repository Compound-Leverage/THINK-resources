# THINK Score -- Readiness Report Template

Blank version of the readiness report THINK Score produces. Use this directly (fill in
your own org and event data by hand) or as the reference format the agent's output should
match. Every `[bracket]` is a placeholder.

---

### Readiness Report

```
[Org Name] -- Capital Event Readiness Report
Date: [date]
Scored against: [event name from the cluster/opportunity map]
Source signal(s): [link(s) or reference to the record(s) this traces back to]

## Score Summary

| Dimension | Score | Max | Notes |
|---|---|---|---|
| Signal Proximity | [0-10] | 10 | [rationale, and cap reason if below 3] |
| Positioning Fit | [0-10] | 10 | [rationale, and cap reason if below 3] |
| Window Timing | [0-10] | 10 | [rationale, and cap reason if below 3] |
| Capacity to Act | [0-10] | 10 | [rationale, and cap reason if below 3] |
| Total | [0-40] | 40 | |

Position: [Not Positioned / Early Signal / Positioned, Capacity Gap / Ready to Capture]

## Gap Analysis

Primary gap: [Detection Gap / Packaging Gap / Timing Gap / Capacity Gap]

[1-2 paragraphs: which dimension(s) scored lowest, why, and what closing that gap would
actually require. If the primary gap is a Capacity Gap, say so plainly -- this is the
finding that leads to a placement conversation.]

## Recommended Next Step

[Specific next action, ranked by urgency -- e.g. build the relationship named in Signal
Proximity, package the offer named in Positioning Fit, resource the capacity gap.]

---
Exceptions flagged: [missing input data, ambiguous event stage, or "none"]
```
