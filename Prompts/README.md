## How to Use

1. Install the plugin from the THINK School marketplace (see the main [README](../README.md))
2. Open the matching prompt file above
3. Paste an example prompt into Claude, replacing placeholders with your own details
4. Adjust wording as needed — these are starting points, not rigid scripts
