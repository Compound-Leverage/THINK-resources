# THINK School - DE Deliverable Templates

Blank versions of the documents each Digital Employee produces, one file per persona.
Use these directly (fill in your own data by hand) or as the reference format a
persona's real output should match. Every file also works as a standalone download, no
plugin install required.

## How to Use

1. Install the plugin from the THINK School marketplace (see the main [README](../README.md)), or just download the one persona file you need
2. Open the matching template file above
3. Use it as a blank form to fill in by hand, or as the reference format to check a persona's real output against
