# Lead Discovery (lead-discovery) -- Deliverable Templates

Blank version of the document this skill produces. lead-discovery is a single standalone
skill, not a multi-persona team, so there's one template below covering the weekly
shortlist output. Use it directly (fill in your own data by hand) or as the reference
format the plugin's output should match. Every `[bracket]` is a placeholder.

---

### Lead Discovery: Weekly Shortlist

One block per qualified lead (Include decision). Target 5-10 per run.

```
Lead Discovery: Weekly Shortlist for [date]

Organization: [Name]
Opportunity: [Title]
Summary: [2-3 sentence plain-English description]
Fit: [Why this matches capabilities]
Scoring: [Fit / Win Probability / Economic Value / Timeline Realism / Strategic Leverage, each 1-5 with justification]
Risks: [Concerns or gaps to address]
Recommended Action: Pursue | Delegate Outreach | Monitor
Deadline: [Date]
Value: [Estimated amount]
Source: [URL]

[Repeat one block per qualified lead]

Monitor list (insufficient data or unclear timeline, revisit next run): [list, or "none"]
Excluded this run: [count], [top disqualifier reasons, or "none"]
```
