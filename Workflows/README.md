# THINK School - DE Automation Setup

How to put each Digital Employee on a recurring schedule instead of running them by
hand, one file per persona. Every file covers two paths: a Claude scheduled routine
(CCR), or ChatGPT Scheduled Tasks. Each file is self-contained, no need to read the
plugin's other persona files first.

## How to Use

1. Install the plugin and fill in its `customization/` files (if it has any)
2. Open the matching workflow file above
3. Follow Option A (Claude scheduled routine) or Option B (ChatGPT Scheduled Tasks), whichever platform you're on
4. If a persona's file notes "full pipeline note lives here," start there when setting up that whole team as a chained sequence
